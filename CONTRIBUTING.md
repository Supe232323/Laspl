# Contributing to Laspl

Thanks for your interest!

## Development

```bash
npm install
npm run tauri dev
```

## Code style

- Rust: `cargo fmt` + `cargo clippy`
- Frontend: keep components small and match the Standard Notes aesthetic
- Prefer clarity over cleverness

## Pull requests

1. Fork & branch from `main`
2. Make your changes
3. Ensure CI passes
4. Open a PR with a clear description

## Security

Please report security issues privately. Do not open public issues for vulnerabilities that could affect users' vaults.
